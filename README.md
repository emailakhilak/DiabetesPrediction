# Diabetes Prediction Website

## Project Overview

This project predicts whether a person has diabetes using Logistic Regression.

Inputs:

- Age
- Glucose
- BMI

Output:

- Diabetes
- No Diabetes

## Technologies Used

- Python
- Flask
- Pandas
- Scikit-learn
- HTML
- CSS

## Workflow

1. Load dataset
2. Handle missing values
3. Train/Test split
4. Balance training data
5. Scale features
6. Train Logistic Regression
7. Save model
8. Build Flask app

## Run Project

Install requirements:

```bash
pip install -r requirements.txt
```

Run:

```bash
python app.py
```
